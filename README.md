## 🚀 How to Run the Notebooks Locally

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd Dojo-Python
   ```

2. **(Optional) Create and activate a virtual environment:**
   ```bash
   python -m venv .venv
   # Windows PowerShell:
   .venv\Scripts\Activate.ps1
   ```

3. **Install Jupyter:**
   ```bash
   pip install jupyter
   ```

4. **Launch Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
   Navigate into any level directory (e.g. `01-Level-1-Basics/Level_01_Basics.ipynb`) to view, run, and modify the solutions.
